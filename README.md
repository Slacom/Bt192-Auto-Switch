# 蓝牙采样率切换（bt192.auto）

Android蓝牙A2DP采样率自动切换实验项目，目标是在受支持设备及编码配置下切换到192kHz。包含手写smali、MT MCP增量构建脚本和源码模型测试；**不是完整Gradle项目，也不是通用蓝牙硬件兼容性保证。**

## 当前状态：016，存在待修实测问题

- 版本名`3`，版本码`68`。016是**有限测试候选**，不是稳定发布版本。
- 已解除D01501：拖动时新child顺序混用旧layout矩形造成的错误保存。在当前纵向、可见、无外margin/weight行契约下，改用逻辑槽位定位。
- **最新用户反馈尚未修复**：Enco Free4、W830连接/重连后可能约1分钟才切换，重新开启自动切换才及时；卡片提起、跟手、换位和落位动画不足。
- [下一轮修改计划](<文档/016实测反馈_连接秒切回归与拖拽动画_修改计划.md>)：先定位连接快速路径回归，再完善拖动动画。目前仅规划，未实施。
- [016有限审核裁决](<工具/v3审查/v3_016/最终裁决/016独立逻辑槽位增量裁决.md>)只覆盖其声明范围，不能推导真实窗口、磁盘、蓝牙功能或所有ROM已通过。报告内部分证据链接属于未上传的本地档案。

## 本地源码模型测试

在项目根目录、Python 3环境中：

```sh
python -B 构建脚本/v3/v3_016/test_deferred_016.py
```

使用真实smali解释器与明确的SDK/View/Prefs桥接，含冻结015负对照。它不是Android ART执行、真实附着窗口手势、实际磁盘持久化或采样率setter测试。其它历史辅助测试不作为“一键全面验收”。

## 构建边界

[增量驱动](<构建脚本/v3/v3_016/mt_session.py>)使用本机MT MCP，并依赖精确015基线APK。该基线、MT签名密钥和本地workspace/session均**不在Git仓库中**；仅clone本仓库不能独立生成与历史证书一致的完整APK。

- 本机桥地址是`http://127.0.0.1:8787/mcp`，不是远程服务；必须由用户手动开启。
