<img src="构建脚本/v3/v3_026/res/drawable-nodpi/bt192_switch.png" width="96" alt="BT192 Switch 图标">

## 构建

需要Python3，以及**用户手动开启**的MT MCP服务（默认`http://127.0.0.1:8787/mcp`）。推荐在能与MT共享文件路径的Android环境运行；MT编译/签名服务不由本仓库安装或启动，产品运行不依赖MT、Shizuku或LSPosed框架。

在仓库根目录执行，输出须使用新的绝对目录，不能放进当前源码目录：

```sh
python -B 构建脚本/v3/v3_026/build.py --out /absolute/new-output prepare
python -B 构建脚本/v3/v3_026/build.py --out /absolute/new-output compile
python -B 构建脚本/v3/v3_026/build.py --out /absolute/new-output unsigned
# 确认本机签名环境后才执行：
python -B 构建脚本/v3/v3_026/build.py --out /absolute/new-output signed
```

signed默认核对发布者原证书指纹。私钥/keystore不在仓库；第三方不能仅凭clone生成同证书更新包。自行修改签名策略并用自己的密钥构建，将产生不同签名，不应卸载/清数据绕过覆盖错误。

MT连接失败先手动开启，禁止自动改设置或绕通道。源码在prepare后被哈希固定；修改后要另选新输出，不覆盖已有候选。详见[使用与验证边界](<文档/仓库使用与验证边界.md>)。
